# Save your Logical English file

After creating or opening your Logical English file, make any changes you wish—add rules, scenarios, or queries.

## How to Save

- Click **File > Save** or press <kbd>Ctrl</kbd>+<kbd>S</kbd> (Windows/Linux) or <kbd>Cmd</kbd>+<kbd>S</kbd> (Mac).
- **Choose a filename ending with `.le`** (for example, `my-program.le`).

> **Why is the `.le` extension important?**  
> The Logical English extension uses the `.le` extension to enable syntax highlighting, querying, and other features.  
> Any filename is allowed, as long as it ends with `.le`.  
> It is good practice to use the same name used for the knowledge base.

## Example Save Dialog

When saving for the first time, enter a name like:

```
dragon.le
```

## Troubleshooting

- If features are not working, check that your file is saved with the `.le` extension.
- You can always rename your file later if needed.
