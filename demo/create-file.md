# Create a Logical English file

Welcome to Logical English! Here you can start a new file or explore sample programs to help you get started.

## Options

- [Create a new empty file](command:logical-english-extension.createSplitFileTemplate)  
  Start with a blank Logical English file. Use this if you want to write your own rules and scenarios from scratch.

- [Open an example file](command:logical-english-extension.createSplitFileDemo)  
  Load a sample Logical English program to see how rules, scenarios, and queries are structured.

## How to use

1. **Choose an option above** to create or open a file.
2. **Edit the file** in the editor. You can write rules, scenarios, and queries using Logical English syntax.
3. **Save the file** with a `.le` extension (for example, `my-program.le`).  
   This ensures the extension recognizes your file and enables all features.

## Example

In both cases you can see the different sections:
- templates - where asterisks delimit the argument places of the predicate
- knowledge base - facts and rules in the systems applicable globally
- scenarios - specific assumptions of facts and rules
- queries - an expression to validate with the knowledge base (and scenario).
